# 审计日志

## 功能说明

通过全局过滤器自动记录每一次 HTTP 请求的关键信息，形成操作审计日志，便于问题排查与安全追溯。

## 记录内容

| 字段 | 说明 |
|------|------|
| 操作人 | 用户 ID、用户名 |
| 请求信息 | 路径、方法、参数、请求体、请求头 |
| 响应信息 | 响应结果、状态码 |
| 性能指标 | 执行耗时（毫秒） |
| 客户端信息 | IP 地址、User-Agent |
| 异常信息 | 异常消息（如有） |

## 敏感字段脱敏

以下字段自动替换为 `***`：

- `Password`、`PasswordHash`、`OldPassword`、`NewPassword`
- `Token`、`RefreshToken`
- `Phone`、`Email`
- `ApiSecret`、`ApiKey`
- `Authorization`、`Cookie` 请求头

## 核心能力

| 能力 | 说明 |
|------|------|
| 自动记录 | 全局 `AuditLogFilter` 无需手动调用 |
| 异步写入 | 后台线程写库，不阻塞主请求 |
| 脱敏处理 | 敏感字段自动替换，防止泄露 |
| 响应截断 | 响应体超过 8000 字符自动截断 |
| 筛选查询 | 支持按用户、方法、状态码、时间范围筛选 |

## 使用方式

审计日志由系统自动记录，无需配置。在【日志管理 → 操作日志】中查看。
