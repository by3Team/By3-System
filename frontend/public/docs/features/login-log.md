# 登录日志

## 功能说明

记录用户每次登录行为的详细信息，包括成功和失败的尝试，用于安全审计和异常检测。

## 记录内容

| 字段 | 说明 |
|------|------|
| 用户名 | 尝试登录的用户名 |
| 登录结果 | 成功 / 失败 |
| 消息 | 成功提示或失败原因 |
| IP 地址 | 客户端 IP |
| 登录时间 | 登录尝试发生的时间 |

## 常见失败原因

| 消息 | 说明 |
|------|------|
| 用户名或密码错误 | 用户名不存在或密码不匹配 |
| 账号已禁用 | 用户 `IsEnabled` 为 false |
| 账号已锁定 | 5 分钟内连续失败 5 次 |

## 核心能力

| 能力 | 说明 |
|------|------|
| 自动记录 | 认证接口自动记录，无需手动调用 |
| 筛选查询 | 支持按用户名、成功/失败、时间范围筛选 |
| 安全分析 | 结合失败记录发现暴力破解行为 |

## 使用方式

登录日志由系统自动记录，无需配置。在【日志管理 → 登录日志】中查看。
