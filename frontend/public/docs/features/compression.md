# 响应压缩

## 功能说明

启用 HTTP 响应压缩，减少网络传输数据量，提升接口响应速度。

## 核心能力

| 能力 | 说明 |
|------|------|
| Gzip 压缩 | 广泛支持的压缩格式 |
| Brotli 压缩 | 更高压缩率，现代浏览器支持 |
| HTTPS 支持 | 默认启用 `EnableForHttps` |
| 自动检测 | 根据 `Accept-Encoding` 自动选择压缩方式 |

## 压缩效果

| 内容类型 | 典型压缩率 |
|---------|-----------|
| JSON 响应 | 60-80% |
| HTML/CSS/JS | 50-80% |
| 二进制文件 | 不压缩（已压缩格式） |

## 注意事项

- 中间件应尽早注册，确保所有响应都被压缩
- 已压缩文件不会重复压缩
- 生产环境建议配合 Nginx 使用，由 Nginx 处理压缩
