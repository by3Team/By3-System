# 组织机构

## 功能说明

提供部门与岗位管理功能，支持树形组织架构和人员关联。

## 部门管理

| 能力 | 说明 |
|------|------|
| 树形结构 | 支持无限层级父子关系 |
| CRUD | 创建、编辑、删除、查看详情 |
| 排序 | 通过 `SortOrder` 控制同级显示顺序 |
| 启用/禁用 | 禁用后部门不可选，已有用户保留关联 |

## 岗位管理

| 能力 | 说明 |
|------|------|
| CRUD | 创建、编辑、删除岗位 |
| 岗位编码 | 唯一标识，用于程序引用 |
| 排序 | 控制列表显示顺序 |
| 启用/禁用 | 禁用后不可分配给新用户 |

## 人员关联

用户可关联所属部门和岗位，在【用户管理】中编辑用户时设置。

## 使用方式

1. 在【系统管理 → 组织机构】中创建部门树（如 公司 → 技术部 → 前端组）
2. 在【系统管理 → 岗位管理】中创建岗位（如 高级工程师、产品经理）
3. 在【用户管理】中为用户设置所属部门和岗位
