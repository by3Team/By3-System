# 文件管理

## 功能说明

提供单文件与多文件上传能力，支持拖拽上传、文件类型校验、分类存储和下载。

## 核心能力

| 能力 | 说明 |
|------|------|
| 单文件上传 | 适合头像、附件等单个文件场景 |
| 多文件上传 | 批量选择、拖拽上传、清空列表 |
| 扩展名校验 | 按字典分类限制可上传的文件类型 |
| 分类存储 | 文件按分类 code 分目录存储 |
| 文件下载 | 支持直接下载原始文件 |
| Excel 导出 | 多文件列表支持导出 |

## 文件类型分类

| 分类 | 说明 | 允许的扩展名（可自定义） |
|------|------|------------------------|
| 通用 | 默认分类 | 无限制 |
| 文档 | 文档类 | pdf, doc, docx, xls, xlsx, ppt, pptx, txt |
| 图片 | 图片文件 | jpg, jpeg, png, gif, bmp, webp |
| 视频 | 视频文件 | mp4, avi, mov, wmv |
| 音频 | 音频文件 | mp3, wav, flac, aac |
| 压缩包 | 压缩文件 | zip, rar, 7z, tar, gz |

> 扩展名通过字典管理中的 `sys_file_category` 类型配置，可自定义扩展。

## 配置项

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `FileUpload__MaxRequestBodySize` | 100MB | 请求体最大大小 |
| `FileUpload__MultipartBodyLengthLimit` | 100MB | 多部分表单最大大小 |
| `FileStorage__UploadPath` | `./uploads` | 文件存储路径 |

## 使用方式

1. 在【字典管理】中配置 `sys_file_category` 字典，定义各分类允许的扩展名
2. 在【文件管理】页面选择文件上传，系统自动校验类型
3. 上传后可在线预览（图片）、下载、删除
