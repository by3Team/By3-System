# 主题设置

## 功能说明

提供个性化界面配置能力，支持主题色、暗黑模式、侧边栏风格、布局选项等设置。修改后自动保存到浏览器本地存储，刷新不丢失。

## 可配置项

| 配置项 | 选项 | 说明 |
|--------|------|------|
| 主题色 | 多种预设颜色 | 系统主色调，影响按钮、链接、选中态等 |
| 暗黑模式 | 浅色 / 深色 | 一键切换整体界面明暗风格 |
| 侧边栏风格 | 深色 / 浅色 | 侧边栏背景色独立于主题模式 |
| 面包屑 | 显示 / 隐藏 | 页面路径导航的显隐控制 |
| 标签页 | 显示 / 隐藏 | 多标签页导航的显隐控制 |
| Logo | 显示 / 隐藏 | 侧边栏顶部 Logo 的显隐控制 |

## 技术实现

- 配置存储在 `localStorage` 的 `settings` 键中
- 使用 CSS 变量（`--el-color-primary` 等）动态切换主题
- Element Plus 暗黑模式通过 `dark` class 切换
- Pinia `settings` Store 管理全局配置状态

## 使用方式

1. 点击页面右上角的设置图标（齿轮）
2. 右侧面板打开主题设置
3. 修改配置后即时生效
4. 配置自动保存到本地，下次访问自动恢复
