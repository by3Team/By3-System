# 定时任务

## 功能说明

基于 Quartz.NET 实现的定时任务调度系统，支持通过界面配置 Cron 表达式、启用/禁用任务、查看执行日志。

## 核心能力

| 能力 | 说明 |
|------|------|
| 任务配置 | 设置名称、分组、类型、Cron 表达式、JSON 配置 |
| 启用/禁用 | 灵活控制任务是否参与调度 |
| 执行日志 | 记录触发时间、执行结果、异常信息、下次触发时间 |
| 手动触发 | 支持手动立即执行一次任务 |
| 并发控制 | 同一任务不会并发执行 |

## 内置任务

### 用户数据种子任务

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `BatchSize` | 5 | 每批生成用户数 |
| `BackupDirectory` | `./backups/users` | 备份目录 |
| `KeepBackupCount` | 7 | 保留备份数 |

功能：批量生成模拟用户 → 执行前 CSV 备份 → 自动清理历史备份。

## Cron 表达式示例

| 表达式 | 说明 |
|--------|------|
| `0 0/5 * * * ?` | 每 5 分钟 |
| `0 0 * * * ?` | 每小时整点 |
| `0 0 2 * * ?` | 每天凌晨 2 点 |
| `0 0 2 * * MON-FRI ?` | 工作日凌晨 2 点 |
| `0 0 0 1 * ?` | 每月 1 号零点 |

## 使用方式

1. 在【任务管理】中创建定时任务，配置 Cron 表达式
2. 根据需要填写 JSON 配置
3. 启用后系统自动调度，可在「执行日志」中查看结果
