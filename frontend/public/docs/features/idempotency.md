# 接口幂等

## 功能说明

通过 `Idempotency-Key` 请求头防止接口重复提交。同一 Key 在 10 分钟内只执行一次，重复请求直接返回缓存结果。

## 工作原理

```
请求到达 → 检查 Idempotency-Key
  ├─ 已存在 → 返回缓存结果
  └─ 不存在 → 执行业务 → 缓存结果 → 返回
```

## 核心能力

| 能力 | 说明 |
|------|------|
| 自动生成 | 前端非 GET/HEAD 请求自动附加唯一 Key（UUID） |
| 服务端校验 | 后端过滤器校验 Key，已处理则返回缓存 |
| 缓存窗口 | Key 有效期 10 分钟，过期后可重复使用 |
| 适用场景 | 表单提交、创建资源、支付等防重操作 |

## 配置项

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 缓存时间 | 10 分钟 | Key 有效期 |
| 缓存方式 | IMemoryCache | 进程内存，重启后失效 |
| 适用方法 | POST/PUT/DELETE | GET/HEAD 不需要幂等 |

## 使用方式

无需额外配置。前端请求自动附加 Key，后端在需要幂等的 Action 上标注 `[ServiceFilter(typeof(IdempotencyFilter))]` 即可。
