# 邮件管理

## 功能说明

提供邮件模板管理、版本控制和邮件发送能力。支持模板变量替换和发送日志记录。

## 核心能力

| 能力 | 说明 |
|------|------|
| 邮件模板 | 维护模板编码、名称、描述、启用状态 |
| 版本管理 | 同一模板可维护多个版本，包含主题、正文、格式 |
| 模板变量 | 正文中使用 `{{变量名}}` 占位，发送时替换 |
| 测试发送 | 发送前可向测试邮箱验证模板效果 |
| 发送日志 | 记录收件人、主题、状态、错误信息、发送时间 |

## 邮件配置参数

| 参数 | 说明 | 示例 |
|------|------|------|
| SmtpHost | SMTP 服务器地址 | smtp.qq.com |
| SmtpPort | SMTP 端口 | 587 |
| Username | 登录用户名 | your@email.com |
| Password | 登录密码/授权码 | **** |
| FromName | 发件人名称 | By3 系统 |
| FromAddress | 发件人地址 | noreply@your-domain.com |
| EnableSsl | 是否启用 SSL | true |

## 使用方式

1. 在【系统设置】中配置邮件发送端（SMTP 服务器信息）
2. 在【邮件管理 → 邮件模板】中创建模板和版本
3. 编写正文时使用 `{{变量名}}` 定义模板变量
4. 点击「测试发送」验证效果，确认后正式发送
5. 在【发送日志】中查看发送记录和状态
