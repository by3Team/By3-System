# 限流保护

## 功能说明

基于固定窗口算法实现接口限流，防止接口被恶意刷取或暴力破解。

## 核心能力

| 能力 | 说明 |
|------|------|
| 全局限流 | 所有接口共享总请求配额 |
| 登录限流 | 登录接口单独配置更严格的限制 |
| 队列处理 | 超限请求可排队，队列满后返回 429 |

## 限流策略

| 策略 | 适用范围 | 默认配置 |
|------|---------|---------|
| 全局限流 | 所有接口 | 200 次/分钟，队列 20 |
| 默认限流 | 普通接口 | 120 次/分钟，队列 10 |
| 登录限流 | `/api/v1/auth/login` | 10 次/分钟，无队列 |

## 配置项

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `RateLimiting__GlobalPermitLimit` | 200 | 全局窗口内最大请求数 |
| `RateLimiting__GlobalWindowMinutes` | 1 | 全局时间窗口（分钟） |
| `RateLimiting__DefaultPermitLimit` | 120 | 单接口窗口内最大请求数 |
| `RateLimiting__LoginPermitLimit` | 10 | 登录接口窗口内最大请求数 |
| `RateLimiting__LoginQueueLimit` | 0 | 登录队列长度（0=直接拒绝） |

## 注意事项

- 集成测试环境自动禁用
- 登录接口无队列，超限直接拒绝
- 生产环境建议根据实际流量调整参数
